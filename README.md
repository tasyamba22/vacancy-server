# Vacancy Server

Серверная часть мобильного приложения для поиска вакансий.  
Разработана в рамках курсовой работы.

## Технологии

- **Kotlin** + **Ktor 2.3.12**
- **PostgreSQL** (локально через Docker)
- **Exposed** (ORM)
- **JWT** аутентификация
- **BCrypt** хеширование паролей
- **HikariCP** пул соединений
