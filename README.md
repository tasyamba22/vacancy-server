# VacancyApp — Backend (Ktor-сервер)

Серверная часть приложения для поиска вакансий.  
Написана на **Kotlin** с использованием фреймворка **Ktor 2.3.12**.

---

## Стек технологий

| Категория        | Инструмент                                      |
|------------------|-------------------------------------------------|
| Язык             | Kotlin 1.9, JVM 17                              |
| Framework        | Ktor 2.3.12 + Netty                             |
| База данных      | PostgreSQL + HikariCP (connection pool)         |
| ORM              | Exposed                                         |
| Аутентификация   | JWT (access + refresh token, auth0)             |
| Хэширование      | BCrypt                                          |
| Сериализация     | kotlinx.serialization                           |
| Контейнеризация  | Docker Compose (PostgreSQL на порту 5433)       |

---

## API

### Аутентификация

| Метод  | Путь             | Тело запроса                  | Ответ                                              |
|--------|------------------|-------------------------------|---------------------------------------------------|
| `POST` | `/auth/register` | `{ email, password }`         | `{ token, refreshToken, role, userId }`           |
| `POST` | `/auth/login`    | `{ email, password }`         | `{ token, refreshToken, role, userId }`           |
| `POST` | `/auth/logout`   | —                             | 200 OK                                             |
| `POST` | `/auth/refresh`  | Bearer refresh-token в заголовке | `{ token, refreshToken, role, userId }`        |

### Вакансии (требуют `Authorization: Bearer <token>`)

| Метод    | Путь                   | Параметры / Тело                                     | Описание                          |
|----------|------------------------|------------------------------------------------------|-----------------------------------|
| `GET`    | `/vacancies`           | —                                                    | Все вакансии                      |
| `GET`    | `/vacancies/search`    | `?query=`                                            | Поиск по названию, компании, описанию |
| `GET`    | `/vacancies/my`        | —                                                    | Вакансии текущего пользователя    |
| `POST`   | `/vacancies`           | `{ title, company, salary?, location?, description? }` | Создать вакансию               |
| `PUT`    | `/vacancies/{id}`      | `{ title?, company?, salary?, location?, description? }` | Обновить вакансию            |
| `DELETE` | `/vacancies/{id}`      | —                                                    | Удалить вакансию                  |

### Избранное (требуют `Authorization: Bearer <token>`)

| Метод    | Путь             | Описание                    |
|----------|------------------|-----------------------------|
| `GET`    | `/favorites`     | Список избранных вакансий   |
| `POST`   | `/favorites/{id}`| Добавить в избранное        |
| `DELETE` | `/favorites/{id}`| Убрать из избранного        |

### Резюме (требуют `Authorization: Bearer <token>`)

| Метод    | Путь                   | Тело запроса                                               | Описание                      |
|----------|------------------------|------------------------------------------------------------|-------------------------------|
| `GET`    | `/resumes/my`          | —                                                          | Своё резюме                   |
| `POST`   | `/resumes`             | `{ fullName, phone?, skills?, experience?, education? }`   | Создать резюме                |
| `PUT`    | `/resumes`             | `{ fullName?, phone?, skills?, experience?, education? }`  | Обновить резюме               |
| `DELETE` | `/resumes`             | —                                                          | Удалить резюме                |
| `GET`    | `/resumes/user/{userId}` | —                                                        | Резюме по userId              |

### Отклики (требуют `Authorization: Bearer <token>`)

| Метод    | Путь                          | Тело запроса                        | Описание                            |
|----------|-------------------------------|-------------------------------------|-------------------------------------|
| `POST`   | `/responses`                  | `{ vacancyId, coverLetter? }`       | Создать отклик                      |
| `GET`    | `/responses/my`               | —                                   | Мои отклики (соискатель)            |
| `GET`    | `/responses/vacancy/{id}`     | —                                   | Отклики на вакансию (работодатель)  |
| `PUT`    | `/responses/{id}/status`      | `{ status }`                        | Изменить статус (PENDING / ACCEPTED / REJECTED) |
| `DELETE` | `/responses/{id}`             | —                                   | Удалить отклик                      |

### Профиль (требуют `Authorization: Bearer <token>`)

| Метод | Путь       | Тело запроса                       | Описание           |
|-------|------------|------------------------------------|--------------------|
| `GET` | `/profile` | —                                  | Получить профиль   |
| `PUT` | `/profile` | `{ firstName?, lastName? }`        | Обновить профиль   |

### Администрирование (требуют `Authorization: Bearer <admin-token>`)

| Метод    | Путь                       | Тело / Параметры       | Описание                          |
|----------|----------------------------|------------------------|-----------------------------------|
| `GET`    | `/admin/users`             | —                      | Список всех пользователей         |
| `PUT`    | `/admin/users/{id}/block`  | —                      | Заблокировать пользователя        |
| `PUT`    | `/admin/users/{id}/unblock`| —                      | Разблокировать пользователя       |
| `PUT`    | `/admin/users/{id}/role`   | `{ role }`             | Изменить роль пользователя        |
| `GET`    | `/admin/stats`             | —                      | Статистика (кол-во пользователей и вакансий) |
| `DELETE` | `/admin/vacancies/{id}`    | —                      | Удалить любую вакансию            |

## База данных

Основные таблицы:

| Таблица      | Описание                                                    |
|--------------|-------------------------------------------------------------|
| `users`      | Пользователи: email, bcrypt-хэш пароля, роль, флаг блокировки |
| `vacancies`  | Вакансии: заголовок, компания, зарплата, локация, описание  |
| `favorites`  | Связь пользователь ↔ вакансия (избранное)                   |
| `resumes`    | Резюме: ФИО, телефон, навыки, опыт, образование             |
| `responses`  | Отклики: vacancyId, resumeId, статус, сопроводительное письмо |

## Запуск

### Вариант 1 — Gradle (локально, облачная БД)

```bash
./gradlew run
```

Сервер запустится на `http://localhost:8080`.

### Вариант 2 — Docker Compose (локальная PostgreSQL)

```bash
docker compose up --build
```

Поднимает два контейнера:

- **`db`** — PostgreSQL 16 на порту `5433`
- **`server`** — Ktor-сервер на порту `8080`
